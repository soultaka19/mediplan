# Archives

Documents **périmés mais conservés**. Rien ici ne décrit le produit tel qu'il est
aujourd'hui ; tout y décrit un état antérieur du projet.

> ⚠️ **Ne pas s'appuyer sur ces fichiers pour comprendre MediPlan.** Plusieurs
> contiennent des informations devenues fausses : adresses `localhost`, compteurs
> décrits comme des valeurs factices, fonctionnalités annoncées « à venir » qui
> sont livrées depuis. Pour l'état réel, partir de [`../README.md`](../README.md).

Ils sont gardés parce qu'un projet noté a besoin de montrer sa progression, pas
seulement son résultat.
